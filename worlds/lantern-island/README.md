# Lantern Island

A compact bilingual coastal mystery, using only built-in storytelling plugins.

Version: `1.0.0` · License: MIT · Languages: English, 简体中文.

Install this directory through **Settings → Packages → Install a world from GitHub** in a Covel build with GitHub world installation support. In earlier builds, ZIP this directory's contents with `world.yaml` at the archive root and use world ZIP import.

The required and recommended plugins are declared in `world.yaml`; installing the world does not install or authorize them. Read [WORLD.md](WORLD.md) or [中文设定](WORLD.zh-CN.md). No network provider or API key is required by the package itself; playing uses the models configured in Covel.
